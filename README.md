A illustrated front page for 22 November: 36 dated stories, three illustrated leads, a region strip, a map, and a date check tying every headline to the edition. The script copies the finished `entry.png` into the bounty output directory.

## Run it

```bash
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to override the default output location (`/output`).
